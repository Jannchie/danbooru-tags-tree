# Danbooru Tags Tree Viewer

This project provides a Vue-based preview UI for the YAML taxonomy data in this repository.

## Stack

- Vue 3 + TypeScript
- Vite powered by `rolldown-vite`
- Vitest for tests
- Oxlint for linting

## Development

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm build
pnpm test
pnpm lint
pnpm lint:fix
```
